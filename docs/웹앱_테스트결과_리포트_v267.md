## 사용자 기능

1. 파일 카드, 견적·정산 표, 앱 작성 견적 목록에서 **날짜 · 프로젝트** 버튼으로 바로 확인한다.
2. **견적일 / 앱 생성일 / 파일 수정일 / 출처 미확인 날짜**를 구별한다. 외부 파일의 원본 생성일은 브라우저가 제공하지 않으므로 미확인으로 표시한다. 파일 수정일을 생성일로 바꿔 표시하지 않는다.
3. 프로젝트를 선택하고 저장한다. 미지정으로 해제할 수 있으며, 보관된 현재 프로젝트와 삭제된 이름도 화면에서 확인할 수 있다. 존재하지 않거나 중복된 프로젝트를 새로 만들지는 않는다.
4. 작성 견적은 `q.project`와 `quote_<id>` 파생파일이 함께 바뀐다. A → B → 미지정 → A 전환 뒤 저장·복원에서도 파생파일은 0개 또는 1개다.
5. 안전 스냅샷과 원자 저장을 통과해야 적용된다. 저장 실패, 편집 중인 초안, 고아/중복 연결, 정산표와 작성 견적의 금액 불일치가 있으면 변경을 중단한다.

## 데이터 영향과 보존 계약

- `quotes[].createdAt`: 새 앱 견적을 만들 때만 기록하는 선택적 앱 생성시각. 외부 불러오기·기존 저장본에는 소급 추가하지 않는다.
- `files[].sourceModifiedAt`: 새 File 입력이 제공한 실제 수정시각의 선택적 ISO 값. 사진 EXIF `when`과 분리한다. 원본 파일 생성시각으로 해석하지 않는다.
- `sourceModifiedAt`은 serialize/applyData(기존 매칭·신규 가상)/원자 복원/동일 Drive ID 재다운로드에서 보존한다. 서버 다운로드로 합성한 `new File()`의 기본 현재시각은 수정일로 기록하지 않는다.
- 기존 파일의 `when`만 있으면 `기존 파일 날짜 (출처 미확인)`로 표시한다. 날짜가 없거나 유효하지 않으면 미확인이다.
- 날짜 없는 신규 외부 XLSX를 읽을 때 오늘 견적일을 자동 주입하지 않는다. 유효한 파일명 날짜 또는 명시된 `견적일` 셀만 사용한다. 기존 저장된 날짜와 금액의 일괄 수정은 없다.
- 외부 견적의 프로젝트 미지정도 재스캔 편집 복원에 유지한다. 원본 파일명·위치·품목·금액·수금·회계 계산식은 변경하지 않는다.
- 프로젝트 연결 변경은 현장별 집계 및 견적 이력 수주 분류에 반영되므로 저장창에서 이 점을 안내한다. 자동 고객 발송·포털 동기화·서버 요청은 하지 않는다.
- 직렬화 최상위 키 추가 없음(41개 유지). PWA 버전과 버전 검사의 핀은 함께 올렸다.
