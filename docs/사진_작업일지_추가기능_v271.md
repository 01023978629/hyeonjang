# 사진 작업일지 추가 기능 (v271)

로컬 개발 후보입니다. 운영 웹 배포는 별도 승인 후 진행합니다.

## 사용할 수 있는 기능

1. **동·호수 / 공용부 조회**: 더보기에서 `사진 작업일지`를 찾아 현장을 선택한 뒤 위치를 고릅니다. 날짜·공정·검색과 함께 사용할 수 있습니다.
2. **작업명 미입력 찾기**: 작업명이 비어 있거나 공백인 사진을 모아 봅니다. 공정만 기록된 사진도 포함됩니다. 내용을 자동 작성하거나 저장하지 않습니다.
3. **글 파일 저장**: 미리보기 아래 `글 파일 저장 (.txt)`를 누르면 현재 조회 기록을 UTF-8 한글 텍스트 파일로 내려받습니다. 사진 선택 여부와 관계없이 조회된 전체 기록을 저장합니다.
4. **세대 화면 바로가기**: `동·호수 관리 → 이 위치 사진 작업일지`로 현재 세대의 기록을 바로 엽니다.

## 위치와 날짜를 읽는 기준

- 기존에 사용자가 연결한 세대 정보만 이용합니다. 파일명·사진 내용으로 동·호수를 추정하지 않습니다.
- `미지정 / 연결 확인 필요`에는 위치가 없거나 연결이 잘못된 사진이 포함됩니다. 오류가 있는 사진을 다른 세대에 자동 배정하지 않습니다.
- 없는 동·호수나 중복된 현장 정보는 전체 사진으로 대체하지 않고 다시 확인하도록 안내합니다.
- 날짜는 앱에 저장된 사진 날짜입니다. 파일 수정일일 수도 있으므로 실제 촬영일·작업 완료일로 단정하지 않습니다.
- 같은 작업명이 여러 세대에 있으면 글에서도 위치별로 구분합니다.

## 글 저장과 공유 시 주의

- 미리보기 글에는 현장명, 동·호수, 공용부 이름, 기록된 작업명이 포함될 수 있습니다. 외부 전달 전에 내용을 확인하세요.
- 고객 연락처·견적 금액·수금·세대 메모·사진 원본은 자동 첨부하지 않습니다. 다만 사용자가 작업명에 직접 넣은 개인정보까지 자동 삭제하지는 않습니다.
- TXT 저장은 다운로드 요청입니다. 성공 여부와 실제 저장 위치는 기기의 다운로드 목록에서 확인하세요. 앱 백업이나 서버 업로드를 뜻하지 않습니다.
- 사진 연결이나 내용이 바뀌면 오래된 미리보기의 저장을 중단하고 다시 조회합니다.
- AI는 위 글의 위치·작업명 등이 전송된다는 안내를 확인한 후에만 실행합니다. 이번 개발·검증에서는 실제 AI 요청을 보내지 않았습니다.

## 유지되는 항목

원본 사진, 프로젝트명, 동·호수 배정, 작업 내용, 견적·정산 계산, 업무 데이터 저장 구조와 서버는 바뀌지 않습니다. 필터와 선택은 화면에서만 유지되며 `초기화`를 누르면 전체 조건으로 돌아갑니다.

Android/iPhone 실제 기기의 다운로드 위치·파일 열기와 터치 흐름은 배포 후 기기별 확인이 필요합니다.
