# v268 서류 목록 · 견적 정산 UI 개선

## 요청과 범위

- 요청: 서류는 견적·정산처럼 가로로, 견적·정산은 더 편하게 변경.
- 기준: 배포된 v267-estimateinfo (`3b337ab`, PR #114).
- 로컬 후보: `hyeonjang-v268-doclistui`.
- 실제 운영 자료, Drive, Apps Script, 고객 발송은 변경하지 않았다. 이번 변경의 공개 배포는 별도 승인 대상이다.

## 변경 사항

1. 서류: PC에서도 파일 아이콘·이름·날짜·현장·도구가 가로 한 줄에 표시된다. 분류별 묶음은 유지한다.
2. 서류 미리보기는 바로 열고, 이름 변경·복사·삭제 등 보조 도구는 ‘더보기’에 모았다. 검색 결과가 없으면 저장된 서류가 없는 것과 구분하고 검색 해제를 제공한다.
3. 견적·정산: 8열을 파일/작업 내용, 프로젝트/날짜, 금액, 관리/상세 입력의 4열로 정리했다. 폰에서는 파일·프로젝트/금액·관리 순으로 쌓아 가로 스크롤을 없앴다.
4. 파일명·프로젝트·고객명 검색, 프로젝트 미지정/집계 제외 필터, 견적일 최신순/금액 높은순 정렬, 전체 보기 복귀를 추가했다.
5. 고객명·견적일·사업자번호·양식 기억·집계 제외는 상세 입력에 모았다. 금액은 접지 않고 항상 편집할 수 있다.
6. 열린 상세 상태와 연속 입력의 Tab 포커스를 유지하고, 한글 IME 조합이 끝나기 전에는 검색창을 재생성하지 않는다.

## 유지한 동작

- `estimateGroups`, `estFinalCandidates`, `byProj` 합산, 월별 견적, 수금, `exportEstimateXLSX` 계산은 그대로다.
- 검색/필터/정렬은 조회 화면에만 적용한다. 합계와 엑셀은 전체 견적의 기존 집계 기준이며 화면에도 이를 명시했다.
- 파일명·프로젝트·금액·수금·선택 상태 및 41개 최상위 직렬화 키를 조회 조작으로 수정하지 않는다.
- 기존 미리보기·날짜/프로젝트 모달·금액 입력 이벤트를 유지했다. 입력 값 저장은 즉시 처리하고 견적 목록의 화면 갱신만 다음 프레임으로 미뤄 Tab 이동을 보존한다.
- 사진 카드 및 다른 탭의 공용 표에는 신규 배치를 적용하지 않는다.
