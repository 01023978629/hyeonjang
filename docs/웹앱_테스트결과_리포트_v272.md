# v272 모바일 서류 줄바꿈 배포 보완

검증일: 2026-09-08 · 대상: `hyeonjang-v272-docwrap`

## 배포 중 발견한 문제

v268~v271 통합 PR #115는 main `7cd0ae3`에 병합되었으나 GitHub Pages 실행
`34130259962`의 전체 검사에서 125/126만 통과해 배포가 중단되었다.
`document-estimate-ui.e2e.js`의 320px 문서 메타데이터가 폭 192px에 대해
scrollWidth 227px로 넘쳤고, 정책상 단독 재시도에서도 실패했다.
기존 성공 배포 v267을 유지했으며 검사 생략이나 강제 배포는 하지 않았다.

## 최소 수정

- `#view .document-row .meta`에 `overflow-wrap:anywhere`만 추가.
- 긴 연속 문자열을 줄바꿈하며 잘라내기나 스크롤 숨김은 사용하지 않는다.
- APP_BUILD, 서비스 워커 캐시, 버전 검사 기준을 함께 v272로 변경.
- 사진 카드, 금액 계산, 업무 자료, 저장 스키마, 서버 및 워크플로는 변경하지 않는다.

## 검증

- 기존 문서/견적 UI 시나리오 11건을 유지하고 320px 메타데이터 검사를 추가했다.
- 긴 가상 고객명·원화 금액·OCR 설명의 원문 DOM 보존, 일반/큰 글씨 2단계,
  가로·세로 잘림 없음, 44px 조작 영역, 사진 화면 불변을 검사한다.
- 개별 정상 실행: 12/12 통과, 페이지 오류 0.
- `metadata` 변이: 새 줄바꿈 속성만 원복하면 신규 폭 검사에서 실패한다.
- 독립 읽기 검토: 배포 차단 결함 없음. 기존 단언을 완화하지 않았다.
- 최종 전체 회귀 및 공개 배포 결과는 실행 완료 후 이 문서에 기록한다.

가상 데이터와 별도 브라우저만 사용했다. 실제 휴대폰 조작과 실제 서버 자료 변경은 하지 않았다.
