# v269 폰 더보기 — 검색·즐겨찾기·실행 보호

## 범위

- 요청: 폰 ‘더보기’의 모든 기능을 확인하고 업그레이드.
- 기준: 로컬 v268 `efbb822`. 이번 후보는 `hyeonjang-v269-mobilemore`이며 v268을 포함한다.
- 인수인계서에 기록된 운영 기준은 v267이다. 이번 작업은 로컬 구현·검증이며 공개 배포하지 않았다.
- 운영 계정·현장 사진·견적·정산·Google Drive·Apps Script·고객 발송은 변경하지 않았다.

## 개선

1. 112개 기능과 4개 기본 바로가기를 이름·분류·설명·공백 무시로 검색한다. 결과 수, 지우기, 결과 없음에서 전체 보기 복귀를 제공한다.
2. 기기별 즐겨찾기 6개를 추가했다. 편집 중 기능/AI 배너/바로가기는 실행되지 않는다. 7번째 추가는 기존 선택을 보존한 채 안내한다.
3. 기능에 짧은 설명을 붙이고 폰에서는 2열로 넓혔다. 좁은 화면의 큰 글씨는 1열로 보여 긴 이름을 보존한다. 입력창 16px, 버튼 44px 이상, 고정 검색/닫기, 안전 영역을 지원한다. 큰 글씨에서 하단 6개 메뉴 이름이 화면 밖으로 잘리던 것도 수정했다.
4. PC 폴더 복원과 휴대폰 안전판을 구분하고, ‘만물인테리어 열기’는 실제 목적지인 Google Drive 만물 폴더로 정정했다.
5. 더보기에서 Sheets 전송·AI 브레인·AI 자율 운영·전체 장부 엑셀·되돌리기는 대상/영향을 확인하고 실행한다. 취소하면 실행하지 않는다. 다른 진입 경로의 권한·실행 정책은 바꾸지 않는다.
6. 최근 사용/즐겨찾기의 손상된 저장값, 알 수 없는 기능, 중복을 안전하게 걸러낸다. 읽는 것만으로 저장값을 변경하지 않는다.
7. 메뉴의 비동기 실패를 처리하고, 닫은 뒤 초점을 더보기 버튼으로 복귀시킨다. 기본 바로가기는 기존 탭 이동/스크롤 처리를 재사용한다.
8. 날씨 조회 성공·실패에서 모달 틀과 닫기를 보존했다. 닫은 요청의 늦은 응답이 다른 화면을 덮지 않으며, 닫은 날씨 AI 응답도 새 화면을 수정하지 않는다.

## 보존 및 검증 경계

- 기존 112개 action과 연결 함수/인자를 보존했다. 독립 명세의 대역 함수로 메뉴 클릭 연결을 검사한다.
- 모든 기능을 운영 계정으로 실행하거나 후속 저장·발송까지 검증한 것이 아니다. 상세 목록과 실행 경계는 `폰_더보기_기능전수점검_v269.md`를 참고한다.
- 신규 UI 저장은 `hj_more_recent`, `hj_more_favorites`만 사용한다. 업무 데이터 직렬화 최상위 키 41개와 서버 계약은 유지한다.
- 더보기 조회/검색/즐겨찾기와 선택된 읽기 전용 화면은 직렬화·IndexedDB·dirty·외부 호출 보존을 확인한다. 탭 이동의 기존 사진 선택 해제는 화면 상태로 구분한다.
- 외부 네트워크·공유·파일 선택·카메라·음성·실제 파일 읽기는 테스트에서 차단하며, 날씨 성공/실패/지연 응답은 합성 대역만 사용한다.

## 검증 결과

최종 `node tests/run-all.js`: **124/124 통과, 실패 0, 재시도 없음, 7.3분(동시 3), 종료코드 0**. 마지막 앱 소스 및 검사식 수정 이후 전체를 재실행했다. 파일당 180초 제한과 최대 1회 재시도 정책은 변경하지 않았다.

첫 전체 실행은 122/124 통과, 종료코드 1(7.5분)이었다. `photo-audit.e2e.js`와 `web-work-bridge.e2e.js`의 정적 경로 검사식이 기존 반환 없는 문장만 허용해 실패했다. 두 검사에서 각 1줄만 명시적 `return`+정확한 함수+무인자를 요구하도록 변경했다. 두 파일 단독 실행은 종료코드 0이며, 메모리상 잘못된 함수/반환 삭제/잘못된 인자 변이 6종은 모두 거절했다. 실제 앱 소스는 변경하지 않았다. 초기 실패 로그도 보존했다.

- 신규 `tests/mobile-more-tools.e2e.js`: 최종 16/16 통과, 종료코드 0. 112개 연결 전수, 4개 기본 탭과 4개 읽기 화면, 5개 실행 확인 취소, 검색/IME/XSS/즐겨찾기, 날씨 성공·실패·지연 응답, 320/360/390/768px 및 큰 글씨 2단계를 검사한다. 페이지 오류·검사 중 외부 요청/공유/파일 선택·다운로드는 0이다.
