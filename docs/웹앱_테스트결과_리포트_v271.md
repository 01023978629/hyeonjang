## 범위

- 동·호수/공용부 및 미지정·연결 확인 필터
- 작업명 미입력 사진 조회 (공정만 기록된 사진 포함)
- 현재 조회 기록의 명시적인 UTF-8 TXT 다운로드
- 세대 관리 화면의 사진 작업일지 바로가기
- 기록 변경 시 오래된 TXT·이미지·AI 결과 차단
- 많은 사진을 조회할 때 세대 목록 중복 검증 제거

`index.html` 단독 작성, 독립 리뷰와 신규 테스트를 분담했다. 실제 업무 자료·고객 파일·Drive·AI·공개 웹을 변경하지 않았다. 로컬 파일 저장 검사는 다운로드를 가로채 Blob 바이트를 확인하는 방식으로 실제 반출 없이 수행했다.

## 독립 검토에서 보완한 사항

- `aptUnits`가 없던 일반 현장에 세대 관리가 도입되면, 출력 글 형식도 바뀌므로 기록 변경 키에 관리 여부를 포함했다.
- 세대 목록을 사진마다 재검증하던 호출을 재사용하도록 수정했다. 독립 PC 합성 100세대·1,000장 data+text에서 검증 호출은 2,001회에서 1회로 줄었다. 실제 휴대폰 속도 측정은 아니다.
- 열려 있는 화면에서 세대명이 바뀌면 위치 선택 라벨을 갱신한다. 삭제된 위치는 전체 조회로 대체하지 않고 오류/0장으로 유지한다.
