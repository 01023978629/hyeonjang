# 사진 작업일지 사용 안내 — v270 로컬 후보

위치: **폰 하단 더보기 → ‘사진 작업일지’ 검색 → 현장 선택**

## 이번 개선

1. 현장명 검색과 보관 현장 표시로 이전 작업 기록도 찾습니다.
2. 전체 기간·최근 7일·시작일/종료일, 공정, 작업명·파일명으로 사진을 좁힙니다.
3. 날짜가 없거나 잘못된 사진은 ‘날짜 미확인’으로 남깁니다. 기간을 정해도 포함 옵션이 켜져 있으면 별도 집계합니다.
4. 앱에 저장된 작업명을 우선하여 날짜별 기록 글을 만듭니다. AI 없이도 미리보기·복사가 가능합니다.
5. 사진을 최대 4장 선택하면 선택한 사진만 작업명·날짜와 함께 이미지로 미리 봅니다. 기존 기기 썸네일이 있으면 선택 목록에 표시하며, 없으면 아이콘으로 표시합니다.
6. 사진 일부를 불러오지 못하면 포함/실패 장수와 제외 파일명을 구분합니다. 미리보기 이후 ‘이미지 저장·공유’를 눌러야 반출됩니다.
7. AI 요약은 전송할 기록을 확인한 다음 요청합니다. 필터를 바꾸거나 다른 창으로 이동하면 이전 결과가 화면을 덮지 않습니다.

## 기록의 의미

- 날짜는 앱에 등록된 사진 날짜입니다. 파일 수정일이 들어 있을 수 있어 실제 촬영일로 확정하지 않습니다.
- 작업명도 등록 기록을 정리한 것입니다. 사진만으로 누수 해결·시공 완료·안전성을 단정하지 않습니다.
- 글은 **조회된 전체 사진 기록**, 이미지는 **선택한 최대 4장**입니다. 서로 범위가 다름을 화면에 안내합니다.
- 이미지에는 현장명과 선택 사진이 들어갑니다. 외부 공유 전 동·호수, 사람, 식별정보가 포함됐는지 확인하세요.
- 같은 식별번호가 중복되거나 식별번호가 없는 사진은 이미지 선택을 막습니다. 사진을 자동 삭제·병합하지 않습니다.

## 바뀌지 않은 것

원본 사진, 현장 배정, 사진 날짜, 견적 금액, 수금, 업무 데이터 저장 구조, Google Drive/Apps Script 서버는 변경하지 않습니다. 조회 조건과 선택 사진은 화면을 닫으면 초기화됩니다.

이번 개선은 로컬 후보입니다. 실제 폰에서의 파일 접근·공유와 운영 계정 AI 연결은 별도 확인 대상이며, 운영 배포는 별도 승인 후 진행합니다.
