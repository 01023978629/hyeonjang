# v270 사진 작업일지 — 조회·기록·선택 이미지

## 범위

- 요청: 더보기 메뉴 개선에 이어 실제 기능 개선도 진행.
- 기준: 로컬 v269 `f5196d7`. 후보 `hyeonjang-v270-photoreport`는 v268·v269를 포함한다.
- 운영 계정·원본 사진·현장 배정·금액·수금·서버는 변경하지 않았다. 공개 배포하지 않았다.
- 실제 기능 내부 점검에서 사진 작업일지의 날짜 누락, 작업명 누락, 비동기 화면 덮기, 이미지 로더 계약 오류를 우선 수정했다. 더보기 모든 기능의 후속 작업까지 운영 실행한 것은 아니다.

## 개선

1. 현장명 공백 무시 검색 및 보관 현장 표시. 기간·공정·작업명·파일명 조회와 결과 없음에서 초기화.
2. 유효 Date·날짜 문자열·ISO 시각을 구분하고 잘못된 날짜는 미확인으로 남긴다. 실제 촬영일이나 완료 여부로 단정하지 않는다.
3. 작업명 우선 날짜별 기록 글 생성. AI 없이 미리보기·명시적 복사가 가능하며 복사 실패 시 수동 복사를 안내한다.
4. 식별번호가 유효하고 유일한 사진 최대 4장만 이미지 선택. 필터 밖으로 숨겨진 선택은 해제하며 전역 사진 선택은 보존한다.
5. 기기에 이미 있는 래스터 data 썸네일만 조회 중 표시한다. 원격 URL·SVG·blob 썸네일을 자동으로 불러오지 않는다.
6. 선택 사진 이미지에는 사진별 작업명·앱 기록 날짜가 들어간다. 1장은 크게, 2~4장은 2열로 배치하고 사진 전체가 보이도록 비율을 유지한다. 실패 장수·제외 파일명, 저장·공유 전 확인을 제공한다.
7. AI 요청 전에 전송할 기록을 확인한다. 사진 파일을 보내거나 고객·견적·수금 전용 필드를 읽지 않는다. 다만 현장명·작업명은 그대로 포함되므로 자유입력 안의 식별정보는 사용자가 확인해야 한다. 명시 요청 이후 Gemini의 기존 한도/중계 정책을 재사용한다.
8. 조회 조건 변경·다른 화면 전환 뒤 AI 결과를 무시한다. 이미지 선택 변경과 조회 조건 변경의 요청 식별을 분리하고 중복 실행을 막는다.
9. 기존 진행 리포트는 `{img,url}` 로더 반환 계약을 지키고 URL을 해제한다. 같은 날의 최신 시각 순서를 보존하며, 하단 문구가 사진과 겹치지 않고 근거 없는 ‘순조롭게 진행’ 표현을 제거했다.
10. 320/390/1280px 및 큰 글씨에 맞는 필터 배치와 44px 이상 닫기·실행 조작 영역을 보완했다.
