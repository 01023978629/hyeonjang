# 고객에게 보낼 문구 추가

2026-10-02 · 로컬 후보 `hyeonjang-v337-customermessages` · 공개 배포 전.

사업자·명함 보내기의 문구 선택에 고객용 20종을 더했다. 기존 16종과 합쳐 기본 제공은 36종이다.
이전 사용자가 수정한 문구는 그대로 유지하며 새 문구는 「추가 추천 문구」에서 직접 선택하거나
「추천 문구 추가」를 눌러야 저장된다. 별도의 고객·프로젝트 자료나 입금 기록을 자동으로 채우지 않는다.

## 추가한 문구

| 상황 | 문구 이름 |
|---|---|
| 상담 시작 | 문의 접수 답변 / 통화 가능 시간 문의 / 현장 사진 추가 요청 |
| 방문·실측 | 방문 전 재확인 / 실측 내용 확인 |
| 견적·자재 | 견적 회신 부탁 / 자재·색상 확인 |
| 작업·점검 | 작업 전 준비 안내 / 공정 중간 확인 / 완료 점검 협의 / 작업 후 사용 문의 |
| 변경 작업 | 변경 작업 협의 (부드럽게) / 변경 작업 협의 (명확하게) |

| 정산 | 정산 안내 (부드럽게) / 정산 확인 요청 (명확하게) / 입금 확인 요청 |
| 서류·A/S | 증빙 서류 문의 / A/S 방문 협의 |

## 복사해서 사용할 수 있는 예시

### 문의 접수 답변

안녕하세요, 만물인테리어입니다.
문의 남겨 주셔서 감사합니다. 요청하신 내용을 확인한 뒤 상담 방법을 안내드리겠습니다.
급하게 확인해야 하는 부분이나 희망 일정이 있으면 함께 알려 주세요.

### 변경 작업 협의 — 부드럽게

안녕하세요, 만물인테리어입니다.
변경을 원하시는 작업 내용을 함께 확인하려고 합니다.
추가·제외할 범위와 비용·일정 영향을 정리해 먼저 안내드리겠습니다.
진행 여부나 다른 대안에 대한 의견을 편하게 말씀해 주세요.

### 일정 조정 안내 — 부드럽게

안녕하세요, 만물인테리어입니다.
작업 일정 조정이 필요한지 고객님과 먼저 상의드리고자 합니다.
사유와 가능한 일정을 확인해 안내드리겠습니다.
일정에 불편이 없도록 고객님께서 가능한 시간도 함께 알려 주세요.

### 정산 확인 요청 — 명확하게

안녕하세요, 만물인테리어입니다.
정산 내역과 입금 여부를 다시 확인하려고 연락드렸습니다.
이미 입금하셨다면 입금일과 입금자명을 알려 주시면 확인하겠습니다.
금액이나 지급 일정에 조정이 필요하다면 말씀해 주세요. 확인 후 협의하겠습니다.

### A/S 방문 협의

안녕하세요, 만물인테리어입니다.
불편하신 부분을 점검하기 위해 방문 가능한 시간을 협의하려고 합니다.
증상 사진과 발생 시점, 방문 가능한 시간대를 알려 주세요.
원인과 조치 범위·비용은 점검 후 확인해 안내드리겠습니다.

모두 일반 초안이다. 실제 작업 상태·금액·일정·입금 여부·협의한 내용을 확인하여 수정하고 받는 사람을 확인한다.
정확한 상황이 주어지지 않았으므로 원인·책임·미납·보상 범위를 단정하거나 임의 숫자를 넣지 않았다.
입금계좌도 임의로 선택하지 않았다. 필요하면 대표가 이번 건의 계좌를 골라 별도로 기재한다.
이대로 보내도 되고, 어투를 더 부드럽게/명확하게 바꿀 수 있다. 앱의 「이 문구 저장」으로 편집본을 재사용할 수 있다.

## 2026-10-03 배포 승인·검사 계획

사용자가 v336 선택 첨부와 v337 문구의 배포를 승인했다. 기존 '미검증/배포 전'은 10월 2일 개발 당시 기록이다.
main은 `bea9902` 그대로이며 최종 제품의 79개 검사, 17개 변이, 정적·단위 38개 파일과 공개 허용목록 검사를 재실행해 통과했다.
병합 전 별도 읽기 전용 PR CI에서 인자 없는 전체 `node tests/run-all.js` 224개와 변이를 실행한다.
PR CI에는 Pages 배포/쓰기 권한·비밀값 참조·실제 자료 연결이 없다. 기존 main 배포 workflow의 전체 게이트는 유지한다.
전체 회귀 성공 뒤 병합하며 Pages 실행·공개 빌드·파일 내용·화면을 확인하기 전 배포 완료로 보고하지 않는다.
최종 CI와 라이브 결과는 해당 PR 검증 기록을 따른다. 실제 고객 전송/휴대폰 수신/서버·계정/PC 종료는 별도 범위다.
