## 변경 범위

### 1. 중복 원본 검증과 이 기기 복구함

- 같은 크기·촬영시간은 **의심 후보**일 뿐이다. 검증 전 사진은 일반 목록과 배정 대상에서 숨기지 않는다.
- 읽을 수 있는 실제 로컬 원본 바이트의 SHA-256과 현장·공정·작업명·동호·촬영일·위치·문서 정보를 비교한다.
- 등록된 원본 해시와 현재 파일이 다르면 보류한다. 썸네일·파일명·크기만으로 정리하지 않는다.
- 원본이 없거나 권한이 없는 서버 기록은 확인 필요로 남긴다. 자동 다운로드·권한 요청은 없다.
- 확인 화면에서 승인해야 목록을 정리한다. 정리 직전 강제 안전판, 원본 재검증, 레코드 변경 검사 후 appState와 복구함을 하나의 IndexedDB 트랜잭션으로 저장한다.
- 저장 실패·저장 공간 부족·다른 탭 충돌이면 트랜잭션을 취소한다. Drive의 `removed_ids` 및 실제 원본은 변경하지 않는다.
- 복구 시 원본 Blob/연결 기록·작업명·동호를 복원하고 새로 생긴 다른 파일은 유지한다. 이미 재스캔된 경로, 삭제/변경된 현장·동호는 복구를 보류한다.
- 경로: **사진 → 사진 도구 → 중복 원본 검증 / 중복 정리 복구함**.

제한:

- 복구함은 **이 기기·이 브라우저 전용**이다. JSON 백업·다른 기기와 공유하지 않는다. 브라우저 데이터를 삭제하면 사라진다.
- 원본을 삭제하거나 재유입을 차단하는 기능이 아니다. 재스캔·Drive 다시 불러오기에서 재등장할 수 있다.
- 검증 한 번에 50장/128MB, 파일당 32MB 이하. 복구함은 30회/메모리 원본 128MB 한도다. 한도 초과 시 원본과 현재 목록을 보존한다.
- 실제 폴더 권한, 휴대폰 원본, 운영 Drive 계정에서의 검증은 수행하지 않았다.

### 2. 자주 쓰는 현장 선택 UI 통일

- 사진 묶음 배정, 서류 배정, 사진 추가, 공정 추가, 견적서 연결/편집, 일정 편집에서 `사진 0개 우선 → 가나다·숫자순`을 사용한다.
- 기존 사진 수는 동영상도 사진 분류로 집계한다. 저장된 프로젝트 배열 순서와 현재 선택은 유지한다.
- 선택 항목이 5개 이상인 위 드롭다운에 현장 검색을 제공한다. 공백 무시 검색, 검색 결과 수, Escape로 검색 지우기를 지원한다.
- 검색 도중 현재 선택을 유지하며 change 이벤트를 발생시키지 않는다.
- 정렬된 공정 선택의 기본 현장과 표시되는 공정 목록을 일치시킨다.
- 모든 부가 기능의 개별 선택기를 바꾼 것은 아니다.

### 3. 원가 미입력 표시

- 원가가 없으면 현장 상세·대시보드 현장별 마진/순마진·합계·프로젝트 PDF에 미확정 안내를 표시한다.
- 일부 현장만 원가가 없는 경우 대시보드 합계도 미확정으로 표시한다.
- 견적 자체가 없으면 견적 입력 필요로 표시한다.
- 원가가 입력되면 기존 계산값을 유지하고 입력 원가 기준임을 명시한다.
- 금융 계산식, 세금 처리, 원본 금액, 엑셀 수치 및 저장 데이터는 변경하지 않는다. 원가가 일부라도 입력됐다는 것이 원가 입력 완료를 보증하지는 않는다.
