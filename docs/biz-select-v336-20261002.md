# 사업자·명함 보내기 — 선택 첨부와 문구 확대

2026-10-02, 로컬 후보 `hyeonjang-v336-bizselect`.

## 사용자 요청과 사용 흐름

상황별 문구를 늘리고, 등록증·통장사본·명함·추가사진을 매번 체크하여 필요한 것만 전달한다.

1. 더보기 또는 PC의 사업자·명함 보내기를 연다. 모든 첨부는 선택 해제 상태다.
2. 등록된 사진 중 필요한 것을 체크한다. 미등록 자료는 사진 등록 후 직접 체크한다.
3. 문구를 선택하고 내용을 수정한다. 기존 사용자 문구는 덮어쓰지 않는다.
4. 고정된 버튼줄의 선택 자료 목록을 확인하고 공유창에서 받을 앱과 사람을 직접 고른다.
5. 파일 공유 미지원이면 선택 이미지 저장과 글 복사를 각각 이용하여 직접 첨부한다.

등록 자료와 문구는 기존처럼 이 기기의 IndexedDB에 보관된다. 체크 상태는 저장/백업/동기화하지 않는다.
문자앱 버튼은 글 전용이다. 문구의 계좌/연락처는 첨부 체크와 별개이므로 글도 확인해야 한다.
공유창 API 완료는 상대방의 수신 증명이 아니며 다운로드 요청도 디스크 저장 완료를 보장하지 않는다.

## 추가 문구 11종

명함 인사, 요청 서류 전달, 관리사무소 업체 등록, 누수·배관 상담, 인테리어 상담,
현장 방문 일정, 견적 검토 안내, 착공 전 확인, 작업 진행 안내, A/S 문의 안내, 추가 자료 요청.
기존 5종을 포함해 기본 제공은 16종이다. 기존 사용자에게는 드롭다운의 추가 추천 문구로 나타난다.
추천 문구를 직접 선택하거나 추천 문구 추가 버튼을 누를 때만 저장하며 동일 이름의 기존 문구는 보존한다.

## 안전 동작

- 공유/다운로드가 동일 `bizSelectedEntries`를 사용하며 선택하지 않은 서류를 자동 첨부하지 않는다.
- 빠른 선택 버튼은 공유를 실행하지 않는다. 미지원/거절/취소에 글만 자동 재공유하거나 다운로드하지 않는다.
- 이미지 URL은 JPEG/PNG/WebP base64 data URL만 허용하고 속성을 escape한다. 일반 등록은 canvas JPEG 변환을 유지한다.
- strict IDB 읽기 실패/손상된 문구 목록은 기본값으로 덮어쓰지 않고 중단한다.
- 화면 세대가 바뀐 등록/저장 결과는 새 창의 이미지·문구·선택을 바꾸지 않는다.
- 같은 세대에서 겹치는 삭제/편집을 차단한다. 추가사진 인덱스 변경 시 원래 선택한 사진을 유지한다.
- 저장 중 편집 컨트롤을 잠그고 공유도 차단한다. 닫기/뒤로가기는 유지한다.
- 실제 사업자등록증/통장 원본, Desktop 사업 자료, Drive, Apps Script, 계정, 자동 문자·알림 설정은 변경하지 않았다.
