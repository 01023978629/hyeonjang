## 보존 및 안전 장치

- 확인 취소 전 사진 추가/서버 요청 없음. 미배정은 명시적으로 선택해야 함.
- 추가 전 강제 안전 스냅샷. 실패하면 가져오기/전송 중단.
- 앱 기록 저장을 먼저 확인하고 파일 전송. 기존 저장 구조/직렬화 키/서버 코드는 변경하지 않음.
- 처리 중 중복 진입 차단. 실패한 파일만 목록에서 구별하고 성공 사진 재선택은 중복 가능성 안내.
- 원본 사진의 영구 보관을 보장한다고 표시하지 않음. 앱 메타데이터 저장과 원본 백업은 별개.
- 기존 v201의 서버 멱등성/오프라인 원본 내구성 계약은 이 후보에 포함하지 않음.
- 실제 Android/iPhone 사진 권한, HEIC 원본, 운영 계정 전송은 자동 테스트와 별도 실기기 확인 대상.

## 실제 휴대폰 확인 순서

1. 공개 배포 승인 및 반영 후 설정/화면에서 v263 버전 확인.
2. 갤러리에서 테스트 사진을 선택하고 취소: 앱 목록과 서버에 추가되지 않는지 확인.
3. 테스트 현장을 선택하고 사진 1장·작업명을 추가: 결과의 백업 확인 장수와 사진의 현장/작업명 확인.
4. 카메라 촬영 후 확인창, 키보드·뒤로가기·가로 화면을 점검.
5. 백업이 확인된 원본만 다른 기기에서 열어 확인. 백업 미확인 원본은 삭제하지 않음.
