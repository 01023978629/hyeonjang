# 현장 갤럭시 앱 설치 안내

이 앱은 기존 현장 웹을 휴대폰 브라우저로 여는 **시험 설치용 Android 연결앱**입니다.
아이폰 앱은 포함하지 않습니다. Android 7.0 이상과 지원 브라우저가 필요하며,
실제 갤럭시에서의 설치·촬영·Drive 업로드는 아직 확인하지 않았습니다.

## 설치하기

1. PC에서 받은 `hyeonjang-galaxy-1.1.0.apk`를 USB 케이블 등으로 갤럭시에 복사합니다.
2. 휴대폰의 **내 파일**에서 APK를 눌러 설치합니다. 전달받은 출처·파일을 먼저 확인합니다.
3. 출처 허용이 필요한 경우 APK를 연 해당 출처만 허용하고, 설치 후 다시 끕니다.
   보안 위험 경고나 Auto Blocker·Play Protect 차단이 뜨면 우회하거나 보호 기능을 끄지 말고 중단합니다.
4. **현장 · 갤럭시** 아이콘을 열고 **현장 웹 열기**를 누릅니다. Chrome이 있으면 우선 연결합니다.
5. Samsung Internet 등 다른 브라우저를 사용해 왔다면 그 브라우저를 기본 브라우저로 유지한 상태에서
   **기본 브라우저로 열기**를 누르고 기존 현장 목록을 확인합니다.

APK 설치가 차단되거나 연결이 되지 않으면 [기존 현장 웹](https://01023978629.github.io/hyeonjang/)을 계속 사용할 수 있습니다.
앱 제거·브라우저 데이터 초기화로 해결하려 하지 마세요.

## 1.1.0의 다음부터 바로 열기

- 버전은 `1.1.0` / versionCode `2`입니다. 첫 실행에는 항상 안내 화면이 나오며 **다음부터 바로 열기**는 기본적으로 꺼져 있습니다.
- 기존 자료가 맞는 브라우저인지 확인한 뒤 체크하면 다음 신규 실행부터 **현장 웹 열기**와 같은 방식으로 연결합니다. 체크한 즉시 열거나 화면 회전·브라우저 복귀 때 다시 열지 않습니다.
- 이 설정은 연결앱에만 저장합니다. Chrome과 Samsung Internet의 자료를 옮기거나 브라우저 기본 설정을 바꾸지 않습니다. Samsung Internet의 기존 자료를 쓰는 분은 브라우저 안내를 확인하고 선택하세요.
- 자동 열기를 끄려면 웹에서 뒤로 돌아와 안내 화면의 체크를 해제하세요. 지원 브라우저가 없으면 기존 오류 안내와 다시 열기 버튼을 사용할 수 있습니다.
- 도메인 연결 [PR #1](https://github.com/01023978629/01023978629.github.io/pull/1)은 병합·배포됐습니다. 2026-10-16 루트 `https://01023978629.github.io/.well-known/assetlinks.json`의 HTTP 200과 이 APK의 인증서 지문 일치를 확인했습니다. 실제 갤럭시에서의 전체 화면 전환은 미검증이며, 브라우저의 연결 검증 전에는 주소줄이 보일 수 있습니다.
- APK 빌드·서명 검증 결과는 해당 릴리스의 `release.json`과 작업 보고서를 확인하세요. 빌드 성공과 실제 갤럭시 설치·업데이트 검증은 별개입니다.

## 처음 확인할 것

- 기존에 쓰던 **같은 브라우저·프로필**인지, 기존 현장 목록이 같은지 먼저 봅니다.
- 목록이 비어 있으면 신규 자료를 저장하거나 서버 자료를 덮지 말고 연결 상태를 확인합니다.
- Chrome과 Samsung Internet의 자료는 자동으로 복사되지 않습니다. PC와 휴대폰도 별도 동기화 확인이 필요합니다.
- 개인정보 없는 작은 시험 사진으로 선택·취소·저장·재조회를 확인합니다.
- Drive 업로드는 본인이 대상 계정과 권한을 확인한 뒤 진행하고, 서버에 원본이 실제 저장됐는지도 확인합니다.

## 알아두기

- 사이트와 앱의 연결 파일은 공개 배포됐지만 브라우저가 아직 검증하지 못하면 주소줄이 보일 수 있습니다. 실제 갤럭시에서 확인이 필요합니다.
- 기존 웹 기능을 사용합니다. 네이티브 촬영 기능이나 화면을 꺼도 계속되는 업로드를 새로 추가한 앱은 아닙니다.
- 업데이트 APK는 같은 서명으로 설치해야 합니다. 서명 오류가 나면 삭제하지 말고 문의합니다.
- `release.json`은 파일 크기·SHA-256·서명 지문을 담은 확인용 파일이며 설치할 필요는 없습니다.
- 공개 다운로드·Play Store·Galaxy Store 배포와 실제 휴대폰 검증은 별도 단계입니다.

설치 후 갤럭시 모델명, Android 버전, 사용 브라우저와 오류 화면을 알려주시면 다음 검증을 이어갈 수 있습니다.
고객 사진·계정 비밀번호·인증 토큰은 보내지 마세요.
